# Out of Scope

This document defines public skill pack boundaries.

## TaosEcho ETL Skills

In scope:

- Normalize user-provided product data into `state.md`.
- Analyze product opportunity from normalized evidence.
- Track evidence level, source quality, field degradation, and conflicts.
- Generate Markdown reports from `state.md` and `analysis_history`.

Out of scope:

- Owning paid data-source authentication.
- Guaranteeing sales, profit, launch, ranking, or legal outcomes.
- Bypassing marketplace, platform, or host restrictions.
- Replacing seller judgment, compliance review, supplier validation, or financial due diligence.
- Storing private user business data inside public examples.

## Harness Setup Skill

In scope:

- Create a durable task operating frame.
- Define context supply, verification gates, recovery paths, and handoff rules.
- Update state files and project entrypoint pointers after user approval.

Out of scope:

- Executing the full downstream project after setup.
- Replacing project-specific coding, research, design, or business skills.
- Changing repository governance without explicit approval.
- Marking verification gates passed without evidence.
