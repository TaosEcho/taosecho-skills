# Evidence Rules

## Levels

| 等级 | 条件 | 输出权限 |
| --- | --- | --- |
| 不足 | 低于 source-quality 线索级阈值 | 只输出缺口提示 |
| 线索级 | 达到线索级阈值或单一来源有明确信号 | 信号观察、证据缺口、建议补数 |
| 判断级 | 达到判断级阈值或主来源与辅助来源同向 | 固定数据表、关键依据 |
| 强判断 | 达到强判断阈值且多源印证 | 阶段判断输入 |

## Source Marks

Every claim cites one of: structured, tabular, textual, document, spoken, user_provided, mixed.
