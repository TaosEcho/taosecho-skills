# Decision Algorithm

## Six Dimensions

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 需求 | 模糊 | 线索 | 判断级以上 |
| 场景 | 泛化 | 有场景 | 具体且重复 |
| 顾虑 | 缺失 | 有顾虑 | 可转动作 |
| 竞品机会 | 缺口模糊 | 单点缺口 | 多竞品重复 |
| 风险 | 高风险未复核 | 风险可列出 | 有复核路径 |
| 页面承接 | 证据薄弱 | 可补证据 | 动作清楚 |

## Stage Output

| 条件 | 阶段判断 |
| --- | --- |
| 总分 9-12 且无否决条件 | 继续推进 |
| 总分 5-8 | 先补关键证据 |
| 总分 0-4 | 暂缓投入 |

## Source Restrictions

- evidence.level=线索级 时，禁止输出“继续推进”。
- source.type=spoken 时，输出“先收集结构化数据”。
