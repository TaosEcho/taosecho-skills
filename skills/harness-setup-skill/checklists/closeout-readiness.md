# Harness Closeout Readiness

Use before closing a harness.

## Required Evidence

- Outcome delivered or explicitly revised.
- Verification gates have evidence.
- Open decisions are recorded.
- Recovery path is still valid.
- Final handoff includes current state, changed files, verification results, and next action.

## Closeout Record

Use this shape:

```text
Outcome:
Verification:
Files changed:
Open risks:
Next owner:
Resume path:
```
